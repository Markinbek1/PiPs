# PiPs

[Русский](README.md) | [English](README.en.md) | [Українська](README.uk.md)

Мій перший проєкт для GitHub. Робив його для себе, вирішив поділитися.

Невелика утиліта для Windows, яка дозволяє переглядати відео в режимі «картинка в картинці» (Picture-in-Picture, PiP) і натискати на вікна прямо під відео.

Застосунок працює в системному треї та керується гарячими клавішами або меню значка. AutoHotkey і сторонні розширення для браузера не потрібні.

## Можливості

- Увімкнення та вимкнення кліків крізь вікно PiP.
- Пауза та продовження відтворення.
- Автоматичне заокруглення кутів PiP із перемикачем у меню.
- Аварійне відновлення кліків.
- Автозавантаження Windows за бажанням користувача.
- Російська, англійська та українська мови інтерфейсу.
- Відновлення стандартних кліків і форми вікна під час звичайного виходу через меню програми.

## Система та браузери

Застосунок призначений для Windows 10/11. macOS та Linux не підтримуються. Основна збірка — під Windows x64; сирці також проходять тести для x86.

Підтримувані браузери:

- **Opera**
- **Microsoft Edge**
- **Google Chrome**

## Запуск

1. Використовуйте готову збірку з розділу Releases або зберіть `pip-toggle.exe` за інструкцією нижче.
2. Помістіть файл у постійну папку з правом запису та запустіть його. Встановлювати Go для роботи готового `.exe` не потрібно.
3. Знайдіть значок PiPs у системному треї біля годинника (він може бути у прихованих піктограмах).
4. Відкрийте відео в Opera, Edge або Chrome та увімкніть режим «картинка в картинці» засобами браузера.
5. Натисніть `Ctrl+Alt+P`: тепер можна натискати на вікна під відео. Повторне натискання поверне звичайне керування PiP.

Під час оновлення спочатку закрийте стару версію через пункт **«Вихід»** у треї, а потім запускайте нову.

## Гарячі клавіші

- `Ctrl+Alt+P` — перемкнути кліки крізь вікно PiP.
- `Ctrl+Alt+Space` — пауза / продовження відтворення.
- `Ctrl+Alt+Shift+P` — аварійне скидання: примусово повернути кліки вікну PiP.

У режимі кліків наскрізь переміщення та кнопки самого PiP недоступні для миші. Спочатку вимкніть цей режим гарячими клавішами або через меню в треї.

## Меню в треї

Меню показує поточний статус і дозволяє перемикати кліки, керувати відтворенням, увімкнути чи вимкнути заокруглення, налаштувати автозавантаження, виконати аварійне скидання та вийти.

Заокруглення активне за замовчуванням під час запуску. Автозавантаження вмикається через меню і зберігається для поточного користувача Windows. Якщо переносите `.exe` в іншу папку, спочатку вимкніть автозавантаження, а після переміщення увімкніть знову вже з нового розташування.

## Мова

Вибрати мову можна в меню трея: **«Мова» → Русский / English / Українська** (російською цей пункт називається **«Язык»**). Меню та сповіщення перемикаються одразу, вибрана мова зберігається між запусками.

## Відомі моменти та діагностика


- **Вікно не знайдено:** переконайтеся, що відкрито окреме штатне спливаюче вікно відео PiP, а не просто вкладку з відео у браузері.
- **Гаряча клавіша не спрацьовує:** перевірте, чи не використовується це сполучення іншою програмою; у такому разі скористайтеся пунктом меню в треї.
- **Відео не можна натиснути або перемістити:** вимкніть кліки крізь вікно або натисніть `Ctrl+Alt+Shift+P`.
- **Пауза спрацьовує на інший плеєр:** якщо пряму команду PiP обробити не вдалося, надсилається стандартна медіаклавіша Windows. Її отримувач залежить від активної медіасесії системи. Спробуйте один раз клацнути по вкладці з відео.

Поруч із `.exe` створюється файл `pip-toggle.log`. Його можна використовувати для діагностики. Перед публікацією логу перевірте власні шляхи та заголовки вікон. Логи виключені з Git через `.gitignore`.

## Збірка із сирців

Потрібні Windows і Go 1.26.3 або новіший. Виконайте команди PowerShell у папці проєкту:

```powershell
go mod download
$env:GOARCH = 'amd64'
go build -mod=readonly -trimpath -ldflags '-H=windowsgui' -o pip-toggle.exe .
```

Прапорець `-H=windowsgui` збирає застосунок без фонового вікна консолі. Для збірки під x86 замініть `amd64` на `386`.

Перевірка вихідного коду:

```powershell
go test -mod=readonly ./...
go vet -mod=readonly ./...
```

Діагностична утиліта показує відомості про відкриті вікна підтримуваних браузерів:

```powershell
go build -mod=readonly -trimpath -o diag.exe ./cmd/diag
.\diag.exe
```
