# PiPs

[Русский](README.md) | [English](README.en.md) | [Українська](README.uk.md)

Мой первый проект для GitHub. Делал его для себя, решил поделиться.

Небольшая утилита для Windows, которая позволяет смотреть видео в режиме «картинка в картинке» (Picture-in-Picture, PiP) и нажимать на окна под видео.

Приложение работает в системном трее и управляется горячими клавишами или меню значка. AutoHotkey и расширение браузера для работы PiPs не нужны.

## Возможности

- Включение и выключение кликов сквозь окно PiP.
- Пауза и продолжение воспроизведения.
- Автоматическое скругление углов PiP с переключателем в меню.
- Аварийное восстановление кликов.
- Автозагрузка Windows по желанию пользователя.
- Русский, английский и украинский языки интерфейса.
- Восстановление кликов и скругления при обычном выходе через меню приложения.

## Система и браузеры

Приложение предназначено для Windows 10/11. macOS и Linux не поддерживаются. Основная сборка — для Windows x64; исходники также проходят тесты для x86.

Поддерживаемые браузеры:

- **Opera**
- **Microsoft Edge**
- **Google Chrome**

## Запуск

1. Используйте готовую сборку из Releases или соберите `pip-toggle.exe` по инструкции ниже.
2. Поместите файл в постоянную папку с правом записи и запустите его. Установка Go для запуска готового `.exe` не нужна.
3. Найдите значок PiPs в системном трее возле часов. Он может быть скрыт в меню дополнительных значков.
4. Откройте видео в Opera, Edge или Chrome и включите режим «картинка в картинке» средствами браузера.
5. Нажмите `Ctrl+Alt+P`: теперь можно нажимать на окна под видео. Повторное нажатие вернёт обычное управление PiP.

При обновлении сначала завершите старую версию через пункт **«Выход»** в трее, затем запускайте новую.

## Горячие клавиши

- `Ctrl+Alt+P` — переключить клики сквозь окно PiP.
- `Ctrl+Alt+Space` — пауза / продолжение воспроизведения.
- `Ctrl+Alt+Shift+P` — аварийный сброс: вернуть клики выбранному окну PiP.

В режиме кликов сквозь окно кнопки и перемещение PiP мышью недоступны. Сначала выключите этот режим горячей клавишей или через меню в трее.

## Меню в трее

Меню показывает текущий режим и позволяет переключить клики, управлять воспроизведением, включить или выключить скругление, настроить автозагрузку, выполнить аварийный сброс и выйти.

Скругление включено при запуске. Автозагрузка включается только через меню и сохраняется для текущего пользователя Windows. Если переносите `.exe` в другую папку, сначала выключите автозагрузку, а после переноса включите её снова из новой версии.

## Язык

Выбрать язык можно в меню трея: **«Язык» → Русский / English / Українська**. Меню и уведомления переключаются сразу, выбранный язык сохраняется между запусками.

## Известные ошибки


- **Окно не найдено:** убедитесь, что открыто отдельное штатное окно видео PiP, а не только вкладка с видео.
- **Горячая клавиша не срабатывает:** проверьте, не занята ли она другой программой; используйте соответствующий пункт меню в трее.
- **Видео нельзя нажать или переместить:** выключите клики сквозь окно либо нажмите `Ctrl+Alt+Shift+P`.
- **Пауза управляет другим приложением:** если прямую команду PiP обработать не удалось, используется общая медиаклавиша Windows. Её получатель зависит от активной медиасессии.

Рядом с `.exe` создаётся файл `pip-toggle.log`. Его можно использовать для диагностики. Перед публикацией лога проверьте личные пути и заголовки окон. Логи исключены из Git через `.gitignore`.

## Сборка из исходников

Нужны Windows и Go 1.26.3 или новее. Выполните команды PowerShell из папки проекта.

```powershell
go mod download
$env:GOARCH = 'amd64'
go build -mod=readonly -trimpath -ldflags '-H=windowsgui' -o pip-toggle.exe .
```

Флаг `-H=windowsgui` создаёт приложение без консольного окна. Для сборки x86 замените `amd64` на `386`.

Проверка исходников:

```powershell
go test -mod=readonly ./...
go vet -mod=readonly ./...
```

Диагностическая утилита показывает сведения о видимых окнах поддерживаемых браузеров:

```powershell
go build -mod=readonly -trimpath -o diag.exe ./cmd/diag
.\diag.exe
```
